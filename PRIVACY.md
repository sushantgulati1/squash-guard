# Squash Guard Privacy Policy

Squash Guard does not collect, store on any server, transmit, or sell any personal data.

- It runs only on `https://github.com/*/*/pull/*` pages.
- It reads the pull request's base branch from the page to decide whether to disable the "Squash and merge" button.
- Your settings (protected branches and orgs/repos) are stored locally in your browser using the extension storage API and never leave your device.
- It makes no network requests.
- The only external link is an optional, user-clicked "Support on Ko-fi" link on the options page.

Contact: https://github.com/sushantgulati1/squash-guard/issues
